# 店舗トップと常設AI会話の整理

管理Issue: #162

## 承認された範囲（2026-09-27）

- 店舗トップの店舗名見出し、説明文、業種トピック帯を削除。店舗名は左上で確認。
- 下部「よく使う機能」を削除。Google口コミをサイドバーの独立リンクにする。
- サイドバーのAIボタンと暗い背景のモーダルを廃止。
- 店舗管理ページのPC右側にAI会話を常設。公開ページ・店舗未選択・運営専用画面は対象外。
- 今日やること、在庫・口コミアラートを中央先頭へ。既存データ・権限・業種別判定は維持。
- ロボットは中央の店舗状況からAI会話内へ移動。

## レスポンシブ・会話仕様

- PC 1280px以上: 右320–400pxを会話用に予約。業務画面を覆わず、独立してスクロール。
- 1279px以下: 下部に常設の会話バー。開くと会話・入力欄が展開し、小さく戻せる。モーダル背景やフォーカストラップなし。業務画面下部に余白を確保。
- 同じ店舗内のクライアント遷移は履歴・入力を保持。別店舗・店舗外への移動では破棄。ローカルストレージへ保存しない。
- 自動送信なし。二重送信防止、通信失敗時の入力復元、90秒でのタイムアウト、店舗移動時の通信破棄。
- 質問先APIの既存認可・読取専用方針を維持。AIに新たなデータアクセス権や外部送信権を与えない。
- 既存Vercel・Supabase・OpenAIを再利用。新規契約、DBスキーマ変更なし。

## 受入条件

- 重複要素なし、Google口コミの選択表示とリンクが正しい。
- 中央の今日やることがPC初期表示上部に見える。ロボットは会話内だけ。
- 店舗トップ、売上、顧客・予約、在庫、口コミ、設定、請求書でAI会話を利用できる。
- 320 / 390 / 768 / 1024 / 1280 / 1366 / 1920pxで横はみ出しや入力・ボタンの隠れを確認。
- 同店舗遷移・別店舗切替・未認証・他法人・閲覧者の認可境界、失敗時の再送、二重送信を検証。
- ステージング検証後にPR作成、CI、マージ、本番Ready確認。実店舗データを書き換えない。
