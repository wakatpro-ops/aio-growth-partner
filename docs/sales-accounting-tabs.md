# 売上・経理のタブ表示

更新日: 2026-10-26

- 売上概要と経理を同一ページで切り替える。URLの `tab=accounting` で経理を直接表示でき、切替時の再取得やスクロール移動を不要にする。キーボードの左右・Home・Endにも対応。
- 合計売上・取引件数・平均取引額は共通上段。登録済み全期間の売上指標であり、経理タブの月次経費とは集計期間が違う。
- 経理は指定月の未削除 `expense_receipts` を法人・店舗で限定し、全ページを取得する。指定なしなら登録経費の最新月、日付なしなら当月。取得失敗・取得上限超過は明示エラーで、0円やサンプルへ置き換えない。
- 税込金額を分類別に合計。確認待ちを含むことを表示し、重複候補・金額不明・日付未入力は区別する。負額を含む月は円グラフにせず分類別金額で表示。多い分類は上位5分類と残りにまとめ、元明細を保持する。
- PCは明細とドーナツを左右、スマホはグラフを先にし、明細を読みやすいカードにする。未登録時の雲付きイメージは表示だけで、業務データとして保存しない。
- 経理集計は店舗オーナー・店長・運営管理者のみ。AIの自由相談は同じ月と集計規則を参照し、分類は最大20件。支払先・伝票原本をAIへ渡さない。会計承認・支払完了・利益・freee送信を意味しない。
- DB変更、店舗の売上・経費への書込、AIモデル・キー・外部連携・課金設定の変更はない。

検証: `npm run test:accounting-overview`、`npm run test:store-ai-import-context`、`npm run test:sales-conversation`、`npm run check:sales-hub`、型検査、lint、本番ビルド、秘密値参照検査。サービス試験は合成1,205件でページング・法人/店舗/削除境界・権限・空/失敗・年月を確認。ローカル限定の一時画面でPC/390px/320px、タブクリック・キーボード・再読み込み・0件を確認し、一時ルートはリリース前に削除。
