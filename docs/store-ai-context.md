# 店舗と画面を理解するAI会話

2026-09-27 利用者承認。常設UIだけでなく、権限内の実データと画面仕様に基づく説明・相談を完成させる。

## 実装・受入範囲

- 共通の版管理されたページ知識、表示タブ・期間・検索条件・詳細IDを毎回解決。
- 顧客・予約を優先し、店舗トップ、売上、商品・在庫、Google口コミ、AIO改善、販促に読み取り専用のデータ文脈を追加。
- ブラウザーが渡す数字や役割を信用せず、要求ごとにサーバーでアカウント・法人・店舗を認可。原価・利益は店長以上。秘密・連絡先・自由記述の顧客メモは送信しない。
- 読み取りの副作用やエラー→0件を排除。部分失敗、未登録、期間内0件、取得上限、未接続を区別。
- ページ移動時にデータに基づく短い一言と質問候補。AI生成を自動課金しない。声かけは更新型カードとし、同じ挨拶で履歴を埋めない。
- 日付・タブ変更、更新操作、復帰時に再取得。古い応答は現在の画面に混ぜず、質問時の画面を明示。入力と同店舗会話は保持。
- 24メッセージまで会話を参照。画面文脈は常に最新を別途提供。店舗外・別店舗・再読み込みでは破棄し、ブラウザー永続保存はしない。
- AI障害は503で通知し質問を保持。架空の定型回答で成功扱いしない。
- 予約変更・削除・外部公開・メール送信をチャットから実行しない。

## 検証

純粋関数の単体試験、合成店舗による実DB/API検証、実AIでの予約回答・継続質問・他法人情報拒否、PC/スマホの操作を検証する。UIの模擬応答だけで回答品質合格としない。実店舗データは変更しない。
