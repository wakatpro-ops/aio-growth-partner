# 予約・顧客ワークベンチと未登録プレビュー

## 今回実装
- `/customers`を予約・顧客・分析/フォローの3タブに統合。旧`/bookings`の期間リンクを互換維持。
- PCは日/週カレンダー、モバイルは時間順リスト。日本時間、日跨ぎ・重複予約も隠さず表示。空白を予約可能と断定しない。
- 2枚の小さい実数KPI。業種に応じた利用回数・最終利用・重要メモのラベル。顧客検索、分類、削除/復元、取込を維持。
- 顧客詳細は概要・予約履歴・メモを先に見せ、編集フォームを折り畳む。
- 分析は登録済み回数の初回/再来/履歴未登録と最終利用の経過日数。周期予測と区別し、グラフの分類から対象リストへ移動。
- AIは小さい相談入口、案内文は既存の未送信下書き。外部送信・自動値引きなし。
- 未登録のみ、雲状の幕をかけた明示的「表示イメージ・サンプルデータ」。サンプルは静的描画のみ、DB/AI/集計/エクスポートへ入れない。
- 必要な情報と得られる表示、取込/手入力/後回しを案内。部分登録は部分的に実表示。
- 共通プレビューを予約・顧客・分析、売上、在庫、成果の適切な未登録領域へ適用。
- 成功した読取で未登録と分かった場合だけプレビュー。実績0、検索0、削除済みのみ、取得失敗、無権限と区別する。無権限はデータ取得より前に拒否。

## 後回し
稼働率、再来予測、移動時間/席数を含む空き枠確定、個人会話のAI送信、自動LINE一斉送信。勤務・利用履歴・媒体別同意/接続/精度条件が揃ったら別issueで提案する。
