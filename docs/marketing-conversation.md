# 会話から集客を進める（#176）

## 動作

- `/marketing` の目的別6カードは閉じた「機能一覧」へ。右AIが次の提案を1つ提示。
- 優先度が高い/予定日を迎えた下書き → 未返信口コミ → その他の下書き → Google接続の準備 → 接続済みGoogle/Instagram投稿 → AIO対策。
- 同順位の投稿提案だけ、利用者・店舗・JST日付を種に重み付き選択。再表示で提案が揺れない。
- 「後で」は24時間、「別の提案」は30分保留。リンクで進んだ提案も24時間保留。完了/接続済みは最新の保存状態から候補を除く。保留は明示操作でのみ行う。
- 投稿先は候補から確定済み。紹介内容（商品選択または自由文）→補足（省略可能）→確認→生成。回答済み情報は保存して再開。
- `growth_actions` と `growth_action_drafts` に下書きとして保存し、文章入りの編集画面へ。画像は既存の投稿画面で追加。口コミ/接続/AIOは既存画面への案内であり、会話から返信や接続を実行しない。
- 一般相談に切り替え可能。この相談は従来どおり読取専用。投稿の準備へ戻ると保存された続きが開く。

## 安全性とデータ

- 新APIで毎回ログイン・店舗・書込権限・機能フラグ・Originを検証。保存/確定RPCも有効な所属・店舗・法人・アカウントを再検証。
- 会話状態は `marketing_conversations` の `(store_id,user_id)` ごと。RLSに加えて匿名/認証JWTの直接テーブル/RPCアクセスを禁止。サーバー専用。
- 全更新はrevisionのCAS。AI生成は120秒のlease、SDK timeout45秒・自動再試行なし。最終保存は行ロック付きの1トランザクションで親/子/監査/完了状態を同時確定。
- 応答を失って再送しても既存の完了下書きを返す。古い生成が新しい処理を上書きできない。本文の読取/生成に失敗した場合は確認段階に戻し、入力を保持。
- DBエラーは未接続や空欄と区別。AIには選択した商品と今回の希望だけを渡す。顧客情報・他店情報・秘密値を渡さず、入力は指示でなく資料として扱う。
- 費用は既存メーターの `marketing_conversation`（管理画面「会話から投稿下書き」）。会話の選択/状態取得だけではAIを呼ばない。
- business draftの編集・削除済み・復元は既存の集客アクション機能。削除済みの本文を会話に再表示しない。会話準備は「この準備をやめる」で解除でき、作成済み下書きは消さない。
- 一括AI提案の再生成は `ai_growth_action` のみ置換し、手作り/会話下書きを削除済みにしない。
- **自動公開、承認、公開ジョブ作成、外部アカウント権限の変更は一切しない。**
