# 集客・販促とAIO改善の統合（2026-10-04）

## 今回の実装範囲

- 全店舗共通で、左メニューの集客・販促を入口とする。
- 投稿・販促 `/marketing` と検索・AI対策 `/marketing/aio-improvement` を同じハブ内のナビで切り替える。
- 目標質問、準備度、改善項目の着手・編集・削除／復元、外部公開確認、再診断、履歴を維持する。DB変更なし。
- 旧 `/aio-improvement` と履歴・詳細URLは307で新URLへ。クエリを保持し、移動先で従来の店舗認可を行う。
- 投稿機能無効時もAIO改善は利用できる。投稿用タブは表示しない。
- AI文脈は新URLでもAIO準備度・質問・選択中の改善項目を参照。別店舗アクセスや書込み権限は従来どおり。
- 目的別6カードとAIの読取専用の動作は今回変更しない。

## 会話主導の集客（Issue #176）

2026-10-04の後続依頼で以下の実装・本番反映を承認。初回統合（#174）とは別変更。

1. 目的別6カードを常時並べず、AIが次の行動を1つ提案。
2. 未接続・期限・公開待ち等の前提条件と優先度を評価。同程度の優先度だけ重み付き抽選。緊急事項は抽選で隠さない。
3. 店舗の保存済み情報を使い、不足分だけ1問ずつ選択肢付きで確認。
4. 会話から店舗・権限を検証して下書きを保存し、対象下書きの確認画面へ移動。公開・配信は利用者が確認。
5. 後で・別の提案・機能一覧も用意し、拒否／完了済み提案を繰り返さない。途中再開・エラー・二重作成を防ぐ。

実装と検証の詳細は `docs/marketing-conversation.md` を参照。公開は引き続き利用者の確認が必要。
